# Tienda de diseños para sublimación

Esta tienda demostrativa es un sitio estático independiente. Abre
`index.html` en un navegador o publica la carpeta completa `tienda-sublimacion/`
en un servicio de hosting estático.

## Qué incluye

- Catálogo de muestra de diseños para tazas, stickers y plantillas.
- Búsqueda y filtros por categoría.
- Carrito de prueba con cantidades y totales.
- Un checkout que informa explícitamente que no procesa pagos ni crea pedidos.

Los productos y precios de ejemplo están definidos en `script.js`.
La moneda de muestra está configurada como CLP. Ajusta esos datos y la moneda
antes de usar la página para presentar un catálogo real.

## Antes de publicar una tienda real

Esta página es solo una demostración de interfaz: no procesa pagos, no registra
pedidos ni entrega archivos. No publiques archivos originales descargables como
recursos estáticos antes de protegerlos. Para vender, integra un proveedor de
pagos, verifica los pagos del lado del servidor y entrega los archivos digitales
solo después de confirmar una transacción válida.
